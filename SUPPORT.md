# SPOOL Support

Use the smallest public channel that fits the problem.

## Usage questions

After GitHub Discussions is enabled for this repository, use **Discussions → Q&A** for setup, architecture and usage questions that are not confirmed bugs. Search existing discussions/issues first so answers remain reusable.

## Bugs

Open a bug report using the repository issue form. Include:

- browser and version,
- exact SPOOL route/workflow stage,
- smallest privacy-safe CSV or generated fixture that reproduces the behavior,
- expected versus observed result,
- console error if relevant,
- whether the issue reproduces with the built-in example.

Never attach private/customer data.

## Migration cases / feature requests

Use the feature/integration issue form. Explain the migration outcome and failure mode rather than proposing a broad implementation first. A reproducible case is significantly more actionable than a feature slogan.

## Security

Do **not** report vulnerabilities that could expose data or bypass SPOOL's execution/storage boundaries in a public issue. Follow `SECURITY.md`.

## Commercial support

There is currently no paid or guaranteed-response support program. GitHub community channels are the canonical public support path for this repository.
